# Example: CIO Vendor Selection

## User Question

We are evaluating three vendors for a new customer data platform. Which vendor will be the most secure, scalable, and advantageous for the customer experience in the long term?

## Suggested Mode

**Vendor Review**

## Expected Output

The council should identify key questions to ask about integration, data ownership, security, vendor lock-in, customer impact, team adoption, and negotiation.

## Try it

Paste the [Master Council Prompt](../prompts/master-council-prompt.md) into your AI assistant, then paste this (replace the brackets with your own context):

```text
Decision: We are choosing between three vendors for a new customer data platform.
Vendors: [Vendor A — key offer], [Vendor B — key offer], [Vendor C — key offer]
Goal: A secure, scalable platform that improves customer experience long term.
Constraints: [budget, integration with existing systems, data residency, timeline]
Concern: Which one will lock us in?
Mode: Vendor Review
```
