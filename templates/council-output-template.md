# Council Output Template

The structure an Executive Council session produces. Use it to capture or share a council's output.

| Section | Content |
|---|---|
| **Decision Reframe** | What is really being decided |
| **Council Perspectives** | One row per member: core insight, greatest opportunity, greatest risk, critical question, first action |
| **Where the Council Agrees** | Three points of consensus |
| **Strategic Tensions** | Two or three real disagreements — which members, and why |
| **Blind Spots** | What the leader is most likely overlooking |
| **30-Day Plan** | |
| **60-Day Plan** | |
| **90-Day Plan** | |
| **Executive Decision Note** | One paragraph for the board or executive committee |
